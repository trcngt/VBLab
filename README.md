# VBLab - Personal Vocabulary Notebook

Ứng dụng học và quản lý từ vựng cá nhân tối giản, trực quan và tiện lợi.

## Tính năng nổi bật
- Đăng nhập bảo mật qua Google Authentication.
- Lưu trữ và đồng bộ hóa đám mây thời gian thực với Cloud Firestore.
- Phân loại từ vựng (Noun, Verb, Adjective, Adverb, Phrase) kết hợp tìm kiếm nhanh.
- Hệ thống Flashcard lật thẻ 3D hỗ trợ chế độ đảo chiều (EN ↔ VI) và xáo trộn thẻ (Shuffle).
- Theo dõi tiến độ học tập và chuỗi ngày học liên tục (Streak).
- Giao diện thân thiện trên cả máy tính và điện thoại di động (Light/Dark mode).
